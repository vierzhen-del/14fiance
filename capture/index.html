🤖 AI 파싱 설정

계좌·월매수 스크린샷을 자동으로 읽어줄 AI를 선택하고 API 키를 입력하세요. 키는 이 기기(브라우저)에만 저장되며, 서버를 거치지 않고 선택한 AI사에 직접 전송됩니다. 타인과 공유하지 마세요.

가장 비용이 안 드는 방법(방식1): 아래 "📋 프롬프트 복사"로 얻은 지침을 API 키 없이 외부 Claude 대화창(claude.ai 구독)에 스크린샷과 함께 붙여넣고, 응답 JSON을 붙여넣기 모드에 넣으세요 — API 크레딧을 전혀 쓰지 않습니다. 자동 파싱(아래)은 방식2: Gemini API가 기본이며, Claude API(방식3)는 크레딧이 소모되므로 명시적으로 선택하거나 교차검증 체크박스를 켰을 때만 호출됩니다.

연결 테스트는 이미지 없이 최소 호출 1건으로 키·모델이 유효한지만 확인합니다(파싱 비용과 무관). 기본 자동 파싱(🤖 자동 파싱 시도)은 Gemini API만 호출합니다 — Claude API는 위에서 provider로 직접 선택했거나 교차검증 체크박스를 켠 경우에만 추가로 호출되어 크레딧이 소모됩니다. 어느 경로로 얻은 결과든(붙여넣기 모드·자동 파싱 모두), 같은 종류의 직전 파싱 결과와 자동으로 대조되어 종목별 수량이 다르면 "채우기" 체크가 기본 해제됩니다.

"💾 키 저장"을 누르면 이 기기 저장(localStorage)과 별개로 설정 파일(myassets-settings.json)도 자동으로 다운로드됩니다 — 앱을 완전히 삭제 후 재설치하면 기기 저장 내용도 함께 지워지므로, 재설치 후엔 이 파일을 "📂 설정 불러오기"로 다시 불러와야 합니다. 이 파일에는 API 키 원문이 그대로 들어있으니 다른 사람과 공유하지 마세요.

📝 파싱 지침 편집(고급) — 방식1(대화창)·방식2(Gemini) 프롬프트

"Claude/대화창용" 지침은 📋 프롬프트 복사(방식1, API 무료) 버튼과 provider를 Claude API로 선택했을 때(방식3)에 공통으로 쓰입니다. "Gemini 전용" 지침은 자동 파싱(방식2)에만 쓰이며 Gemini 특성에 맞게 별도로 튜닝돼 있습니다. 각각 저장하면 이 기기에 계속 남고, 기본값 복원으로 되돌릴 수 있습니다.

"노션 SOP 요약 복사" 버튼으로 만든 요약을 어느 AI 세션에 붙여넣을 계획인지 선택하세요 — 앱이 그 AI를 대신 호출하지는 않고, 문구만 맞춰줍니다(예: "클로드 코드 세션에 붙여넣어…").
