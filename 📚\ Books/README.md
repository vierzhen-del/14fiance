# 📚 Books

책 읽기, 요약, 학습 정리를 위한 폴더입니다.

## 📖 구조

- `[책제목]-[저자]-정리.md`: 책 읽고 정리한 노트
- `[책제목]-[저자]-요약.md`: 책 주요 내용 요약
- `[책제목]-[저자]-인용.md`: 인상적인 문구 모음

## 💡 사용 예시

```
📚 Books/
├── 원자의-습관-제임스-클리어-정리.md
├── 원자의-습관-제임스-클리어-요약.md
├── 원자의-습관-제임스-클리어-인용.md
└── ...
```
