# 종목조회 — 국내 ETF 조회 · 노션 기록

조회 항목: 주가 · 최근 배당금 · 배당률(연율화) · 월배당 여부 · 분배금 주기.

- **개별 배당락일(정확한 날짜)은 조회하지 않는다** — 네이버에 공개 API가 없어 확인 불가(2026-07 확인).

  SOP)에 등록돼 있으면 그 값을 쓰고, 없으면 조회해서 "확인안됨"으로 둔다 — **추측 금지**.

## B. 보유종목 배당 조회 — 개인 14RAE 노션 SOP 갱신

사용자가 **본인이 실제 보유한** 종목의 "이번 달 배당금"을 물으면(A와 별개, 개인 포트폴리오 관리 목적):

1. "💹 14RAE 배당기준 마스터" 관련 노션 페이지에서 그 종목의 등록 여부 · 등록된 분배금 주기
   (월초/월중/월말) · 마지막 기록일을 먼저 확인한다.
2. **7일 재조회 규칙**: 오늘 날짜와 노션 SOP의 마지막 조회일 차이가 **7일 이상일 때만** 다시 조회해
   노션 SOP를 갱신한다. 7일 미만이면 재조회 없이 기존 SOP 값으로 예측한다(불필요한 반복 조회 방지).
3. **배당금 결정 우선순위**
   - ① 해당 기간의 **확정 배당금**(예: "6월 배당 정산"처럼 공시·확인된 DPS)이 있으면 그 값을 최우선.
   - ② 확정값이 없으면 **조회 시점 주가 × 분배율(등록된 배당률)** 로 계산.
4. 조회(또는 계산)한 DPS를 그 종목의 노션 SOP 이력 페이지에 새 "실행이력"으로 기록한다
   (기존 세션 기록 패턴 — 예: "14RAE 세션 — YYYY-MM-DD ..." 페이지들 — 을 따라 하위 페이지 추가).
   **조회일도 함께 남겨야** 다음 재조회 시 7일 규칙을 판단할 수 있다.

## C. 배당 실지급금 확정 — 매달 5·18·30일 자동 점검 (2026-08-08 신설)

배당ETF 지급주기(월초5일/월중15일/월말30일)에 맞춰 지급일이 지난 뒤 **실제 지급된 확정 DPS**를
조회해 전월 배당금을 확정한다. B(사용자 질문에 응답하는 온디맨드 조회)와 달리 **스케줄 트리거로
매달 3회 자동 실행**된다(`create_trigger`, cron `0 0 5,18,30 * *` = 매일 09:00 KST).

- **5일** → 월초5일 그룹(전월 지급 완료) 종목 확인
- **18일** → 월중15일 그룹 확인 — 지급일(15일)+3일 여유를 둔 것은 공시·데이터 반영 시차 때문
- **30일** → 월말30일 그룹 확인

절차:
1. "💹 14RAE 배당기준 마스터" SOP(`3865efd0-e462-81c4-9a72-c9bbc70dcea0`)에서 오늘 날짜 그룹에
   해당하는 `지급일`(월초5일/월중15일/월말30일) 종목만 추린다.
2. 각 종목의 **실제 지급 확정 DPS**를 WebSearch(운용사 공식 공시·분배내역, DataGuide 등)로 조회한다.
   확인 안 되면 "확인안됨"으로 두고 **추측·역산으로 채우지 않는다**(CLAUDE.md 원칙과 동일).
3. 확정값을 배당기준 마스터 SOP 표에 반영하고 `divType`을 `"실확"`으로 갱신, 갱신이력에 조회일과
   함께 기록한다(다음 재조회 판단·감사 추적용).
4. "계좌 종목 현황" SOP(수량 SSOT, `3955efd0-e462-81da-b7f3-cbd905a15dfd`)는 **쓰기는 하지 않고
   읽기만** 한다 — 5단계(전월 총액 계산)에 각 종목 보유수량이 필요해서다. 수량 자체를 고치는 건
   여전히 계좌 반영 절차(캡처→SOP 갱신) 몫이다.
5. **30일 실행에서만** — 이번 달 월초5일·월중15일·월말30일 세 그룹이 전부 확인된 시점이므로,
   "계좌 종목 현황" SOP에서 각 종목 보유수량을 읽어와 **`Σ(보유수량 × 방금 확인한 실지급 DPS)`**로
   전월 총 배당금을 계산한다. 결과를 배당기준 마스터 SOP에 **"📊 월별 확정 배당금 실적"** 표(없으면
   새로 만든다 — 컬럼: 년월 · 총액 · 산출근거)로 한 행 추가한다. 확인 안 된 종목(`divType`이 여전히
   "확인안됨")이 있으면 그 종목은 합계에서 제외하고 비고에 제외 종목을 명시한다(추측 금지 원칙 유지).
6. 갱신 후 사용자에게 별도 알림은 하지 않는다(다음 "자산 업데이트" 요청 시 최신 divRate와
   전월 확정 총액이 자동 반영됨) — 단, 등록 배당률과 크게 어긋나는 값을 발견하면(15%↑ 괴리) 발견
   사실을 노션 갱신이력에 남겨 다음 세션이 자가진단에서 참조할 수 있게 한다.
