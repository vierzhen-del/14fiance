# 트레이딩 대시보드 활용 가능성 검토 및 최적 제안

> **검토 대상**: Claude Code × TradingView Desktop MCP 브리지를 활용한 개인 투자 종목 트레이딩 대시보드 구축
>
> **투자 종목**: 비트코인 · 미국 반도체 지수(SOX/SOXX) · 코스피 · 삼성전자 · SK하이닉스
>
> **작성일**: 2026-07-12

---

## 1. 배경

노션에 정리된 분석 노트에 따르면, 한 개발자가 **Chrome DevTools Protocol(CDP)** 을 이용해 Claude Code와 TradingView Desktop을 연결하는 **로컬 MCP 브리지**를 오픈소스로 공개했습니다. 이를 통해 AI가 자연어 명령만으로 다음 작업을 수행할 수 있습니다.

- 차트 데이터 읽기, 심볼·타임프레임 전환
- Pine Script 작성 및 백테스트 자동 실행
- 얼럿(Alert) 생성, 차트 드로잉 관리
- 차트 스크린샷 캡처, 리플레이 모드 활용
- 연결 상태 확인(Health Check)

단, **비공식 통합**(TradingView 내부 인터페이스 의존)이므로 플랫폼 업데이트 시 작동이 중단될 수 있는 유지보수 리스크가 있습니다.

이 문서는 위 시스템을 본인 투자 종목의 트레이딩 대시보드로 활용할 수 있는지 **가능성 · 비용 · 기존 시스템 연계** 관점에서 검토하고 최적안을 제안합니다.

## 2. 종목별 활용 가능성 검토

### 2.1 심볼 매핑

| 투자 자산 | TradingView 심볼 | 시세 제공 | 실시간 여부 |
|---|---|---|---|
| 비트코인 (KRW) | `UPBIT:BTCKRW`, `BITHUMB:BTCKRW` | 업비트/빗썸 | **실시간 무료** ✅ |
| 비트코인 (USD) | `BINANCE:BTCUSDT`, `COINBASE:BTCUSD` | 바이낸스/코인베이스 | **실시간 무료** ✅ |
| 미국 반도체 지수 | `SOX` (필라델피아 반도체지수) | Nasdaq | 지연 15분 무료 / 실시간 유료 애드온 |
| 반도체 ETF | `NASDAQ:SOXX`, `AMEX:SMH` | Nasdaq/NYSE | 지연 무료 / Cboe One 기준 일부 실시간 무료 |
| 코스피 지수 | `KRX:KOSPI` | 한국거래소 | 지연 무료 / 실시간 유료 애드온 |
| 삼성전자 | `KRX:005930` | 한국거래소 | 지연 무료 / 실시간 유료 애드온 |
| SK하이닉스 | `KRX:000660` | 한국거래소 | 지연 무료 / 실시간 유료 애드온 |

### 2.2 결론: 3개 자산군 모두 활용 가능 ✅

- **암호화폐(비트코인)**: TradingView가 실시간 시세를 무료 제공하므로 가장 즉시성이 높음. MCP 브리지의 데모 사례(비트코인 선물 스캔, 지지선 식별, 커스텀 지표 생성)가 이미 검증됨.
- **미국 반도체**: 지수(SOX)와 ETF(SOXX/SMH) 모두 차트·스크리너·얼럿 지원. 한국 시간대 특성상 미국 장중이 아닌 시간의 분석 위주라면 지연 시세로도 충분.
- **국내 주식**: TradingView가 KRX를 공식 지원 (차트·재무·스크리너 포함). 실시간이 필요하면 유료 플랜 + KRX 시세 애드온(월 $2~10 수준) 추가. 국내 증권사 HTS와 병행한다면 지연 시세로도 분석 용도는 충분.

MCP 브리지 기능(심볼 전환, 얼럿, Pine Script, 스크린샷)은 **심볼과 무관하게 동일하게 작동**하므로, 위 종목 전체를 하나의 워치리스트/멀티차트 레이아웃으로 구성해 AI가 순회 분석하는 대시보드 워크플로우가 가능합니다.

| 미국 거래소 실시간 애드온 | 월 $2~10 수준/거래소 | 선택 사항 |

### 3.2 시나리오별 월 비용

| 시나리오 | 구성 | 월 비용 | 적합 대상 |
|---|---|---|---|
| **A. 무료 검증** | Basic + 지연 시세 + 브리지 | **$0** | 브리지 검증·워크플로우 실험 단계 |
| **B. 권장** | Essential(연납) + KRX 실시간 | **약 $17~25** | 국내장 실시간 모니터링 + AI 분석 |
| **C. 확장** | Plus(연납) + KRX/미국 실시간 | **약 $35~50** | 멀티차트 대시보드·얼럿 다수 운영 |

> 💡 **권장**: 시나리오 A로 2~4주 검증 후, 워크플로우가 정착되면 B로 전환. 30일 무료 체험으로 유료 기능을 먼저 확인 가능.

## 4. 리스크 및 한계

| 리스크 | 내용 | 완화 방안 |
|---|---|---|
| **비공식 연동 파손** | TradingView 데스크톱 업데이트 시 브리지 작동 중단 가능 | 자체 대시보드(Layer 2) 병행 구축으로 헤지, 앱 자동업데이트 지연 설정 |
| **로컬 의존** | 데스크톱 앱 + 브리지가 항상 실행 중이어야 함 | 상시 실행 PC 지정, Health Check 활용 |
| **주문 실행 부적합** | 브리지는 차트 제어용 — 실제 매매 주문 자동화는 미지원·위험 | **모니터링·분석·얼럿 용도로 한정** (매매는 기존 증권사/거래소 앱) |
| **KRX 실시간 비용** | 실시간 국내 시세는 유료 | 지연 시세 + 증권사 HTS 병행, 또는 한국투자증권 OpenAPI(무료) 활용 |
| **AI 오판** | AI 분석 결과에 의존한 매매 판단 위험 | 보조 지표로만 사용, 최종 판단은 본인 |

## 5. 최적 제안: 2계층 하이브리드 아키텍처

TradingView MCP 브리지의 즉시성(설치만 하면 바로 사용)과 파손 리스크를 모두 고려하여, **브리지를 1차 도구로 즉시 활용하되 자체 대시보드를 점진 구축해 리스크를 헤지**하는 2계층 구조를 제안합니다.

### Layer 1 — TradingView MCP 브리지 (즉시 활용)

- 워치리스트 구성: `UPBIT:BTCKRW` / `SOX` / `NASDAQ:SOXX` / `KRX:KOSPI` / `KRX:005930` / `KRX:000660`
- Claude에게 자연어로 지시: 종목 순회 스캔 → 지지/저항 식별 → 스크린샷 리포트 → 조건 충족 시 얼럿 생성
- Pine Script 커스텀 지표(예: 반도체 지수 대비 삼성전자 상대강도)를 AI가 생성·백테스트

### Layer 2 — 자체 실시간 대시보드 (`realtime-trading` 레포, 점진 구축)

무료 공개 API 기반으로 브리지와 독립적인 웹 대시보드를 구축:

| 자산 | 데이터 소스 | 비용 |
|---|---|---|
| 비트코인 | Upbit WebSocket / Binance WebSocket | 무료 |
| 코스피·삼성전자·SK하이닉스 | 한국투자증권 OpenAPI (실시간 웹소켓) | 무료 (계좌 필요) |
| SOX/SOXX | Yahoo Finance / FMP API | 무료~저가 |

### 단계별 로드맵

| 단계 | 기간 | 내용 | 완료 기준 |
|---|---|---|---|
| **Phase 1** | 1주 | 브리지 설치·연결 검증, 워치리스트·얼럿 구성, AI 분석 워크플로우 정착 | 6개 종목 순회 스캔 리포트 자동 생성 |
| **Phase 2** | 2~4주 | 자체 대시보드 MVP — Upbit/KIS 웹소켓 실시간 시세 보드 | 브라우저에서 6개 종목 실시간 조회 |
| **Phase 3** | 이후 | 얼럿 통합(브리지+자체), 노션 자동 데일리 리포트, 포트폴리오 손익 트래킹 | 노션에 일일 시황 자동 기록 |

### 총평

| 평가 항목 | 판정 |
|---|---|
| 기술적 가능성 | ✅ 높음 — 3개 자산군 모두 TradingView 지원, 브리지 기능 심볼 무관 |
| 초기 비용 | ✅ $0로 시작 가능 (권장 구성 월 $17~25) |
| 지속 가능성 | ⚠️ 브리지 단독은 파손 리스크 → 2계층 하이브리드로 보완 |
| 기존 시스템 연계 | ✅ 노션(리포트 저장) · Claude Code(기존 구독) · 증권사 앱(주문) 역할 분담 명확 |
